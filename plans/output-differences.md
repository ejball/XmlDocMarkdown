# Output Differences Plan

Snapshot: May 30, 2026, comparing the current regenerated `docs` output with `master` output.

## Ignored Source-Assembly Differences

- New fixture types and members are expected output additions, including modern C# syntax fixtures such as `ExampleModernSyntax`, `ExampleReadOnlyRefStruct`, static abstract interface members, and `ReadRefReadonly`.
- Documentation for APIs added or removed from `XmlDocGen.Core` is expected to differ because the source assembly changed.

## Differences Not Caused by Source Assemblies

- Output paths changed from the master layout, e.g. `ExampleAssembly/ExampleClass.md`, to the new assembly/namespace nested layout, e.g. `ExampleAssembly/ExampleAssembly/ExampleClass.md`.
- The new output created namespace files such as `XmlDocGen.Core.Xml.md`; master has no default namespace files and folds every namespace section into the assembly page.
- The new output created one page per overload with suffixes such as `Overloaded-Int32.md`, while master grouped overloads into shared pages such as `Overloaded.md` and noted counts in overview tables.
- Assembly pages gained a synthetic `## Namespaces` table and namespace sections gained a synthetic `## Types` heading; master renders namespace sections directly on the assembly page.
- Namespace overview tables used the generic `name` header; master uses `public type`.
- Overview table links wrapped the full display text. Master links only the symbol name, leaving kind/modifier text such as `class` and suffix text such as `{ get; set; }` outside the link.
- Heading text changed; master included node kind suffixes such as `ExampleStruct structure`, while the new output used only the node name.
- Default output no longer emitted master’s See Also backlinks for namespace/interface/source-file links.
- Long C# signatures are emitted on one line instead of master’s wrapped formatting.
- Inline parameter and type-parameter references now render as code links to anchors instead of master’s italic text.
- Generated comments intentionally changed to `DO NOT EDIT: generated by XmlDocGen for ExampleAssembly`; stale master-era generated pages that still had `xmldocmd` comments were removed from `docs`.

## Plan

- Make the default page map mimic master paths for assemblies, types, and member groups, with namespace nodes folded onto their assembly page instead of writing namespace files.
- Render assembly pages as namespace sections with no `## Namespaces` heading, and render namespace type tables directly with no `## Types` heading and the `public type` header.
- Restore master-style overview rows with C#-style display text, grouped overload rows, and links restricted to symbol names.
- Restore default See Also backlinks for namespaces, containing types, base/interface types, and source links when `XmlDocSourceLinks` is enabled.
- Add targeted golden tests for namespace folding, headings, overview rows, overload pages, See Also output, parameter-reference rendering, and generated comments.
- Regenerate `docs` and all sample snapshots, accepting semantic equivalence rather than byte-for-byte parity with master.
- A temporary comparison harness may be used locally to compare against `master`, but it must not be committed.
