# Output Differences Plan

Snapshot: May 30, 2026, comparing the current regenerated `docs` output with `master` output.

## Ignored Source-Assembly Differences

- New fixture types and members are expected output additions, including modern C# syntax fixtures such as `ExampleModernSyntax`, `ExampleReadOnlyRefStruct`, static abstract interface members, and `ReadRefReadonly`.
- Documentation for APIs added or removed from `XmlDocGen.Core` is expected to differ because the source assembly changed.

## Differences Not Caused by Source Assemblies

- Output paths changed from the master layout, e.g. `ExampleAssembly/ExampleClass.md`, to the new assembly/namespace nested layout, e.g. `ExampleAssembly/ExampleAssembly/ExampleClass.md`.
- The new output creates one page per overload with suffixes such as `Overloaded-Int32.md`, while master grouped overloads into shared pages such as `Overloaded.md` and noted counts in overview tables.
- Overview tables changed from master’s `Public Members` table with C#-like member labels to a generic `Members` table with `name`, `kind`, and `summary` columns.
- Member labels no longer include modifiers, accessors, generic arity display, ellipses for parameters, or operator keywords in overview tables.
- Heading text changed; master included node kind suffixes such as `ExampleStruct structure`, while the new output uses only the node name.
- Default output no longer emits master’s See Also backlinks for namespace/interface/source-file links.
- Long C# signatures are emitted on one line instead of master’s wrapped formatting.
- Inline parameter and type-parameter references now render as code links to anchors instead of master’s italic text.
- Generated comments intentionally changed to `DO NOT EDIT: generated by XmlDocGen for ExampleAssembly`; stale master-era generated pages that still had `xmldocmd` comments were removed from `docs`.

## Plan

- Make the default page map mimic master paths for assemblies, namespaces, types, and member groups.
- Restore master-style overview tables with C#-style display text and grouped overload rows.
- Restore default See Also backlinks for namespaces, containing types, base/interface types, and source links when `XmlDocSourceLinks` is enabled.
- Add targeted golden tests for headings, overview rows, overload pages, See Also output, parameter-reference rendering, and generated comments.
- Regenerate `docs` and all sample snapshots, accepting semantic equivalence rather than byte-for-byte parity with master.
