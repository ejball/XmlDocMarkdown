# Samples.MultiAssembly

Documents multiple assemblies in one run so generated pages can cross-link within one documentation tree.

The output contains pages for both sample assemblies. [SampleExtraAssembly.md](output/SampleExtraAssembly.md) links into the primary sample assembly, while [ExtraWidget.md](output/SampleExtraAssembly/ExtraWidget.md) documents a type that returns `SampleAssembly.Widget`.
