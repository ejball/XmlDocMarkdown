# Samples.Default

Generates out-of-the-box Markdown documentation with the default one-page-per-member layout.

This sample is the baseline for the others. [SampleAssembly.md](output/SampleAssembly.md) shows the assembly overview, [Widget.md](output/SampleAssembly/Widget.md) shows a type page, [Format.md](output/SampleAssembly/Widget/Format.md) shows a member page, and [WidgetKind.md](output/SampleAssembly/WidgetKind.md) shows enum values on the enum page.
