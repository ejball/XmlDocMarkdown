# Samples.CustomPageMap

Uses a custom `XmlDocPageMap` subclass to place assemblies, namespaces, and types under bespoke paths.

The output demonstrates custom file placement. [api/index.md](output/api/index.md) is the assembly page, [api/namespaces/SampleAssembly.md](output/api/namespaces/SampleAssembly.md) is a namespace page, and [api/types/Widget.md](output/api/types/Widget.md) is a type page.
