# Samples.LibraryApi

Uses the library layers directly instead of the root app and command-line wrapper.

This sample builds the tree, pages, and renderer directly from library APIs instead of `XmlDocGenApp`. The resulting output matches the default shape; [SampleAssembly.md](output/SampleAssembly.md) and [Widget.md](output/SampleAssembly/Widget.md) are representative pages.
